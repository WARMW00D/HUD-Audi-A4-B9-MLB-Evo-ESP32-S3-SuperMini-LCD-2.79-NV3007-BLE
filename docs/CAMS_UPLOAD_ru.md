# Загрузка базы камер (cams.bin) с телефона

С v31.0.0 базу камер можно обновлять из приложения HUD Control (1.5.0+) по BLE. Программатор не нужен.

## Как пользоваться
1. На ПК соберите базу `gen_cams.py` (в готовом виде это `cams_*.bin`, заголовок `CAM1`). Индекс `cams.idx` HUD **не использует**: записи отсортированы в самом `cams.bin`, поиск идёт двоичным поиском прямо в PSRAM.
2. Перенесите файл на телефон, в приложении подключитесь к HUD, раздел «База камер» → «Выбрать cams.bin» → «Загрузить базу».
3. HUD стирает сектора флеши W25Q128, принимает данные, проверяет SHA-256, затем записывает первую страницу (сигнатуру `CAM1`), перечитывает базу из флеши в PSRAM и сверяет SHA-256 ещё раз. Перезагрузка не нужна.

## Что нужно знать
- Максимальный размер ограничен свободной PSRAM (2 МБ на SuperMini) и ёмкостью флеши; приложение сообщит, если файл не помещается.
- Сигнатура пишется последней. Оборванная загрузка оставляет флешь «пустой» (после перезагрузки камеры выключены, в журнале `no CAM1 database`), но не наполовину записанную базу. Загрузку можно просто повторить. Работающая в PSRAM база не затрагивается до COMMIT.
- На время COMMIT (1–3 с) камеры выключаются, затем включаются с новой базой. Если база не прошла проверку, камеры остаются выключенными до следующей успешной загрузки или перезагрузки.
- Права как у OTA: сопряжённый и аутентифицированный владелец HUD.

## Скорость
OTA использует «пакет → ответ → чтение статуса» (около 6–8 КБ/с). Для базы камер пакеты идут потоком (Write Without Response), по 8 пакетов в окне, после окна приложение читает статус. HUD не прерывает загрузку из-за пропущенного или повторного пакета: он их игнорирует, а приложение продолжает с подтверждённого смещения `received`. Во время передачи запрашивается интервал соединения 7.5–15 мс.

## Протокол (v1, как OTA)
Сервис `74d0a200-3d92-4f50-9b1a-478142000011`, control `…0012` (READ/WRITE), data `…0013` (WRITE и WRITE_NR). Команды control: START `01 + размер(4) + SHA-256(32)`, END `02`, COMMIT `03`, CANCEL `04`. Данные: `offset(4) + до 240 байт`. Статус 16 байт: `[1, состояние, ошибка, 0, received(4), total(4), максимальный размер(4)]`. Первый пакет обязан начинаться с `CAM1`, а размер файла равен `16 + 12 × N`.
